EJECUCION

1. Clonar repositorio con:
   git clone

2. Al clonar, ubicarse en consola dentro de la carpeta del codigo y archivo de datos con:
   cd so

3. Ejecutar el codigo escribiendo lo siguiente en consola:
   node hola.js
   (Previa instalacion de node.js)
   
4. Ejecucion del codigo:
   Al ejecutar el codigo, introducir el nombre del archivo txt de datos (data.txt), el cual debe estar en el mismo directorio (cd so).
   Introducir quantum.

5. Seguidos los pasos correctamente, se ejecutaran las simulaciones de FIFO, LIFO y ROUND ROBIN, al igual que las comparaciones pertinentes.
